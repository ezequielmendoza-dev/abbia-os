# Contexto General del Proyecto (Golden E-Shop)

## 1. Visión General
Golden E-Shop es una plataforma de comercio electrónico modular diseñada para venta minorista de productos digitales con soporte para pagos en múltiples monedas.

## 2. Stack Tecnológico
- **Frontend:** Next.js 14 (App Router), React, TailwindCSS, Lucide Icons.
- **Backend:** Node.js, Fastify, TypeScript, Prisma ORM.
- **Base de Datos:** PostgreSQL 16.
- **Infraestructura:** Docker, GitHub Actions, AWS ECS.
- **Testing:** Vitest (unit), Playwright (E2E).
