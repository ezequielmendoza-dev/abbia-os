# UI/UX Design Spec: FEAT-001 Autenticación de Usuarios

> **Iniciativa:** FEAT-001-user-auth  
> **Diseñador:** UI Designer  
> **Estado:** Approved  

---

## 1. Vistas y Layouts
- **Pantalla `/login`:** Formulario centrado en card responsivo (380px max width en Desktop, full-width con 16px padding en Mobile).
- **Pantalla `/register`:** Formulario con medidor visual de fortaleza de contraseña.

## 2. Tokens de Diseño y Accesibilidad
- **Colores:** Primario `#3b82f6` (Blue 500), Background `#0f172a` (Slate 900), Texto `#f8fafc` (Slate 50).
- **Contraste:** Ratio 7.2:1 (Supera estándar WCAG AA).
- **Inputs:** `aria-required="true"`, focus ring visible `#60a5fa`.
